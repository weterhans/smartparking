# 🤖 Klasifikasi – Smart Parking System

Folder ini berisi kode dan model untuk bagian **Klasifikasi** pada sistem Smart Parking.

## Deskripsi

Bagian Klasifikasi bertanggung jawab untuk memproses data dari sensor dan melakukan klasifikasi status slot parkir (kosong / terisi) menggunakan algoritma Machine Learning.

## Struktur Folder (Rencana)

```
Klasifikasi/
├── dataset/          # Dataset training & testing
├── model/            # File model yang sudah di-train (.pkl, .h5, dll)
├── notebooks/        # Jupyter Notebook untuk eksplorasi data
├── src/              # Source code utama klasifikasi
│   └── classify.py
├── requirements.txt  # Dependensi Python
└── README.md
```

## Setup & Cara Menjalankan

> 📌 Bagian ini akan diisi oleh anggota tim yang bertanggung jawab.

```bash
# Install dependencies
pip install -r requirements.txt

# Jalankan klasifikasi
python src/classify.py
```
